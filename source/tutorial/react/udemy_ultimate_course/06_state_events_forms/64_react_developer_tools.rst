React Developer Tools
=====================
Go to https://react.dev/learn/react-developer-tools and find the download link
for your browser.

After installation, in the developer window, there are now the **Components** and
**Profile** tab.

The **Components** view shows the component tree of the currently displayed React application.

Selecting a component shows the properties the selected component has as ``props``
and the state variables under ``hooks`` (as ``useState()`` is a hook function).

State variables can be directly changed here.
