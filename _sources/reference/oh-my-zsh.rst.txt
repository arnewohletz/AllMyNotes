Oh-My-Zsh - Commands
====================
Plugins
-------
List all enabled plugins

.. code-block:: none

    $ echo $plugins

List all available built-in plugins

.. code-block:: none

    $ omz plugin list

Enable and disable a plugin

.. code-block:: none

    $ omz plugin enable <plugin>
    $ omz plugin disable <plugin>

Get plugin information

.. code-block:: none

    $ omz plugin info <plugin>
