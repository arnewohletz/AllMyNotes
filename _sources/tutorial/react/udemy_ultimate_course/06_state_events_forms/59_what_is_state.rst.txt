What is state in React?
=======================
* state is the most important concept in React
* data that a component **can hold over time**, that it needs to **remember**
  throughout the application's lifecycle
* "components memory"
* **"state variable" / "piece of state**: a single variable in a component
  (component state)
* updating **component state** triggers React to **re-render the component**
  (creates a new component view)

    .. hint::

        A component view is the visual representation of a single component.

* state allows the developer to do:

    * update the components view by re-rending it
    * persist local variables between renders
